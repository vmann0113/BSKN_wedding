웨딩드레스 보기 전 꿀팁

피팅에서 후회 안 하는 법 · 웨딩여기 wedhere.co.kr

드레스는 "예쁜 것"보다 "내 예식장·체형에 맞는 것"이 먼저입니다.

방문 전

  • 예식장 분위기(호텔·채플·야외)와 계절 먼저 확정 — 드레스 라인이 달라집니다
  • 피팅비 확인 (샵마다 5~10만원, 계약 시 차감 여부)
  • 원하는 스타일 사진 저장 (촬영 금지 샵이 많아 기억에 의존하면 헷갈림)

피팅 당일

  • 목이 파인 옷·볼륨 없는 속옷·힐 지참
  • 피팅 사진 촬영 가능 여부 미리 문의
  • 앉았을 때·뒤태·팔 움직임까지 확인 (본식은 3시간 이상 입어요)

계약 전

  • 포함사항 범위: 드레스 + 턱시도 + 메이크업 + 부케 + 혼구용품까지인지
  • 신상·수입 드레스 추가금 (100~200만원까지 벌어짐) — 기본 라인 먼저 보기
  • 가봉 횟수·일정, 본식 당일 헬퍼비 별도 여부
  • 피팅 드레스와 본식 드레스가 같은 등급인지 확인
