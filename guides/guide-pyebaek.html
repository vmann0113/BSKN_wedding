폐백 가이드

할지 말지부터 준비까지 · 웨딩여기 wedhere.co.kr

폐백은 신부가 시댁 어른들께 첫인사를 드리는 전통 의례입니다. 요즘은 생략하거나 간소화하는 경우가 많아요 — 정답은 양가 협의입니다.

먼저 정할 것

  • 진행 여부: 양가 어른들 의향을 먼저 확인 (한쪽만 원하면 간소식 추천)
  • 범위: 시댁만 vs 양가 모두 절 올리기 (요즘은 양가 모두가 늘어나는 추세)
  • 장소: 웨딩홀 폐백실 유무·사용료 확인

준비물

  • 폐백 음식: 대추고임(자손 번창)·밤·폐백닭 또는 육포 — 지역마다 구성이 다르니 양가 어른께 확인
  • 한복·폐백복: 대여로 충분 (웨딩홀·한복집 패키지 확인)
  • 수모(도우미) 진행비 — 보통 별도

간단 절차

  • 시부모님께 큰절 → 대추·밤 던져주시며 덕담 → 시댁 친척 순서로 인사 → (협의 시) 친정 부모님께도 동일하게
  • 전체 20~30분이면 충분합니다

비용 가이드

  • 폐백 음식 30~60만원, 폐백실 사용료·수모비 별도 — 생략하면 그대로 절약, 간소화(음식 축소·절만)도 좋은 선택
